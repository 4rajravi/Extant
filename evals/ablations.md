## temporal

As-of correctness, from amended directions: for each consecutive pair of versions with text, one paragraph that changed, asked twice with the same words, once on the last day of the old version and once on the first day of the new, each with its own version's paragraph as gold. **The query is the old paragraph's own first sentence**, chosen to be distinctive to its direction, so lexical overlap is maximal and paraphrase is never tested: this set measures whether the right version comes back on the date, not whether a compliance officer's question finds it. Pairs are matched by paragraph number, so a renumbering between versions makes a wrong pair; the label audit measures how often. Smallest coverage of the sets: 158 version pairs, from the amended directions that had a changed paragraph with a distinctive first sentence. 28 of those provisions were deleted by the amendment, so only their old side is asked (288 queries, not 316); builder 1 missed unbracketed deletion markers and asked 11 queries whose gold was a bare `*****`, fixed in builder 2 before any test-half run.

## withdrawal

Supersession detection, from RBI's published withdrawal lists: a seeded sample of 1,000 of the 10,019 withdrawn circulars. **Near trivial once the list is ingested**: the fast path looks the reference up in the same list, so this is a regression canary, not a discriminating benchmark. Labels are document level (the withdrawing notification), and those notifications are not themselves in the index, so there is no paragraph recall. The 154 circulars published without a reference ("Mail Box Clarification") can only be asked by title; the hybrid path never consults the withdrawal list, so those always miss. The holdout here is the Department of Supervision list announced 31 July 2026.
